# 2026 我的技术栈选择

回顾今年使用的技术工具栈，分享背后的选择逻辑与学习心得。

## 后端：.NET

在企业级仓储系统开发中，.NET 依然是我的首选：

- **性能**：.NET 8 的 JIT 和 AOT 编译带来显著性能提升
- **生态**：成熟的 ORM、消息队列、日志等基础设施
- **工具链**：Visual Studio + ReSharper 提供极致的开发体验

## 前端：React + TypeScript

React 生态的成熟度让它成为大多数项目的合理选择：

- **类型安全**：TypeScript 让大型项目更可维护
- **状态管理**：根据项目规模选择 Context、Zustand 或 Jotai
- **样式方案**：Tailwind CSS 的原子化 CSS 大幅提升开发效率

## 创意编程：TouchDesigner + Three.js

这两个工具分别代表了实时视觉的两个方向：

- **TouchDesigner**：节点化的视觉编程，适合现场演出和装置艺术
- **Three.js**：Web 端的 3D 引擎，适合交互式网页体验

## 选择原则

选择技术栈不只关乎技术本身，还关乎团队、生态和长期可维护性。没有银弹，只有最合适的选择。
