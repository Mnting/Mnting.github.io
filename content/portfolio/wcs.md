# 智能仓储管理系统 WCS

基于 .NET 和 WPF 构建的仓库控制系统（Warehouse Control System），实现自动化设备调度、任务分配与实时监控。

## 核心功能

- **设备抽象层**：统一管理输送线、堆垛机、AGV 等多种自动化设备
- **任务调度引擎**：基于优先级和路径最优的任务分配算法
- **实时监控面板**：可视化展示仓库运行状态、设备状态和任务进度
- **异常处理**：自动检测设备故障并触发降级策略

## 技术栈

- C# / .NET Framework
- WPF + MVVM
- SQL Server
- OPC UA 通信协议
