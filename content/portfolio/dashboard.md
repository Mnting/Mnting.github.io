# 数据可视化仪表盘

面向企业级应用的数据可视化平台，支持多种图表类型、实时数据流与自定义主题。

## 核心功能

- **多图表类型**：折线图、柱状图、饼图、热力图、散点图等
- **实时数据流**：WebSocket 连接，毫秒级数据更新
- **自定义主题**：支持品牌色定制和暗色模式
- **导出功能**：支持 PNG、SVG、PDF 导出

## 技术栈

- React + TypeScript
- D3.js 数据绑定和动画
- WebSocket 实时通信
- 模块化图表组件架构
