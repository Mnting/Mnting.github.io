# 个人博客系统

使用 React + Three.js 构建的个人博客，集成点云动画、响应式设计与内容管理。

## 亮点

- **点云背景动画**：Three.js 实现 3D 粒子背景，随鼠标交互
- **暗色主题**：完整的深色模式支持
- **响应式设计**：移动端到桌面端完美适配
- **Markdown 渲染**：支持全文 markdown 写作

## 技术栈

- React 18 + TypeScript
- Three.js + React Three Fiber
- Tailwind CSS
- react-markdown + remark-gfm
